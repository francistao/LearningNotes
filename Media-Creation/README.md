# 自媒体创作笔记

记录自媒体创作的心得体会、技巧方法和案例分析。

## 目录结构

- **内容策划/** - 选题、策划、内容日历
- **写作技巧/** - 文案创作、标题技巧
- **视频制作/** - 视频拍摄、剪辑、后期
- **平台运营/** - 各平台运营策略和技巧
- **案例分析/** - 优秀案例和复盘总结

## 创作流程

1. **选题策划** - 确定创作方向和主题
2. **素材收集** - 收集相关资料和案例
3. **内容创作** - 写作/拍摄/制作
4. **编辑优化** - 修改完善内容
5. **发布运营** - 选择平台，发布推广
6. **数据分析** - 跟踪效果，总结经验

## 平台特点

### 文字类
- **微信公众号**: 深度内容，用户粘性强
- **知乎**: 专业问答，SEO友好
- **小红书**: 图文并茂，年轻用户多

### 视频类
- **抖音/快手**: 短视频，娱乐性强
- **B站**: 中长视频，内容深度
- **视频号**: 微信生态，社交传播

## 创作原则

1. **价值优先**: 为读者提供实用价值
2. **真实可信**: 内容真实，建立信任
3. **持续输出**: 保持更新频率
4. **用户思维**: 站在读者角度思考
5. **差异化**: 形成个人特色和风格
